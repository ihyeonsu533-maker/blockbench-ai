조선시대 NPC 제작기 v6

이미지의 픽셀 느낌을 유지하며 성별·머리·키·체형·얼굴을 조절하는 Blockbench 모델 제작기야. 64×64 스킨 텍스처를 모델 안에 포함해.

키·체형·얼굴형은 모델 크기와 비율에 반영되고, 머리 선택은 별도 머리 장식 파츠로 생성돼.

왕실 예복
64×64 픽셀 스킨 미리보기

의상은 제작기에 포함된 64×64 픽셀 스킨을 사용해. 신분을 바꾸면 기본 의상이 자동 선택돼.

성별에 따라 어울리는 머리 스타일을 고를 수 있어. 왕을 선택하면 남성·왕실 예복으로 자동 설정돼.

※ 현재 겉 레이어는 별도 3D 파츠로 생성돼. 원본 스킨의 레이어 픽셀을 그대로 분리해 입히는 정식 플레이어 스킨 방식과는 다르므로, Blockbench에서 텍스처 정렬을 확인해줘.

파일 여는 법

Blockbench 웹 → 파일 → 모델 열기 → 다운로드한 .bbmodel 선택. 텍스처는 모델 안에 포함돼.
